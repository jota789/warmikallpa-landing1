
# WarmiKallpa — Tu seguridad, tu decisión

Landing Page responsive desarrollada por **AyniTech** para el curso de **Diseño de Experimentos de Ingeniería de Software / Diseño UX/UI** (UPC).

**WarmiKallpa** es una propuesta tecnológica enfocada en la prevención, orientación y respuesta discreta frente a situaciones de acoso sexual en el transporte público de Lima Metropolitana (Metropolitano, Metro de Lima y corredores complementarios).

## Características principales

- **Diseño responsive (Desktop, Tablet y Mobile):** Una sola base de código en HTML5, CSS3 y JavaScript sin pérdida de contenidos ni funcionalidades entre resoluciones.
- **Identidad visual y accesibilidad:** Paleta cromática institucional (Violeta Kallpa `#4B2A7B`, Violeta noche `#2F1A52`, Fucsia Warmi `#B3174F`, Turquesa Ayni `#0F766E`, Lavanda niebla `#F7F3FB`), tipografías *Poppins* e *Inter*, navegación por teclado, atributos ARIA, textos alternativos e indicadores visuales que no dependen únicamente del color, además de soporte para `prefers-reduced-motion`.
- **Mapa colaborativo interactivo:** Implementado con **Leaflet** y OpenStreetMap, con zonas de ejemplo etiquetadas por nivel de riesgo, selección de puntos de prueba y consulta de ubicación.
- **Demostración de alerta silenciosa (SOS):** Simulación interactiva con estados (*lista*, *enviando*, *enviada*, *en cola sin conexión* y *cancelada*), sin enviar alertas reales ni contactar servicios de emergencia.
